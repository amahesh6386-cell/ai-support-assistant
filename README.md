# Autonomous AI Support & Lead Orchestration Engine 🚀

An enterprise-grade full-stack AI automation system built with **FastAPI**, **React**, **n8n**, and **Groq (Llama 3)**.

## 📌 Features
- **Dynamic Frontend Dashboard:** Built with React & Tailwind CSS for real-time user query submission and live response tracking.
- **FastAPI Engine:** Custom async backend to handle API routing, request validation, and webhook dispatch.
- **n8n Multi-Agent Orchestration:** Complex workflow handling LLM system constraints, email routing via Gmail API, and lead tracking.
- **Ultra-Fast LLM Processing:** Leverages Groq API for sub-second, contextual AI responses.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Python, FastAPI
- **Automation & Orchestration:** n8n, Webhooks
- **AI/LLM:** Groq API (Llama 3)
